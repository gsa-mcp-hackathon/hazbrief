== Cause ==
Not a conflict of content. In each attempt the round, under its lease, committed main's store (`_record_journals`),
which moved main by a housekeeping commit; it then rebased the branch over that commit. git's union driver, replaying
HB-189's commits that first wrote the three reconciled events, put back the copies HB-189 had removed by hand, so
`dedupe()` dropped them again and appended a `kept_events_deduped` line to main's store. That line was written after
the store was committed and before `git merge --ff-only`, and the branch also changes the event log of the graph (held privately), so git
refused to overwrite the dirty file. The next attempt committed that line, which moved main again, and the cycle
repeated until merge_attempts (3) ran out. Main moving during the session (Desktop's handoff, filings) only set the
first rebase going. Which replayed commit restores the copies (HB-189's hand removal 9e977247, the dispatcher's own
drop commits, or the commits that wrote the lines) is not isolated here; the counts above show only that every
rebase of this branch restored them.
